Beginner 10K Plan: 10 Weeks to Build Endurance and Finish Strong

Updated August 2026 · 5 min read

Wanting a bigger long run and needing recoverable easy days often conflict. Skip the 5K base and jump mileage, and the plan becomes injury math. Assumes continuous easy running (ideally a recent 5K block); three runs/week, mostly easy. Tools: Pace Calculator, Zone 2 Calculator, Pace Chart, Race Predictor, VO2 Max Calculator.

Guardrails Before You Build

  • Easy days conversational; quality controlled, not all-out
  • Long run drives endurance — progress time gradually
  • Missed week → repeat it; two sick weeks → restart mid-plan, not peak week

Numeric scenario: Mid-plan long run ~55–60 min. If the last 15 min drifts >20–25 sec/km vs the first 15 at same effort (or HR +8–10 bpm at fixed pace), cut next long run 8–10 min and skip quality once — no catch-up intervals.

Expert Note

Gray-zone easy days are the usual reason long runs flatten in weeks 6–8.

Decision rule: if long-run form collapses or shin/Achilles pain alters gait, cut quality first and shorten the long run before touching the race date.

10-Week Schedule

Week 1

  • Run 1Easy 28-30 min (run-walk as needed)
  • Run 2Easy 25 min + 4 x 20 sec relaxed strides
  • Run 3Long easy run 35 min

Week 2

  • Run 1Easy 30 min
  • Run 2Steady intervals: 4 x 3 min controlled, 2 min easy between
  • Run 3Long easy run 40 min

Week 3

  • Run 1Easy 32-35 min
  • Run 2Progression 25 min: easy start, steady finish
  • Run 3Long easy run 45 min

Week 4

  • Run 1Easy 35 min
  • Run 2Steady intervals: 3 x 6 min controlled, 2-3 min easy between
  • Run 3Long easy run 50 min

Week 5

  • Run 1Easy 35-38 min
  • Run 2Tempo intro: 2 x 10 min comfortably hard, 3 min easy between
  • Run 3Long easy run 55 min

Week 6

  • Run 1Easy 38-40 min
  • Run 2Steady intervals: 5 x 4 min controlled, 2 min easy between
  • Run 3Long easy run 60 min

Week 7

  • Run 1Easy 35 min + 4 short strides
  • Run 2Progression 30 min with final 10 min steady
  • Run 3Long easy run 62-65 min

Week 8

  • Run 1Easy 40 min
  • Run 210K prep: 3 x 8 min steady, 3 min easy between
  • Run 3Long easy run 65 min

Week 9 (Start Taper)

  • Run 1Easy 32-35 min
  • Run 2Tune-up: 2 x 6 min steady + 4 short strides
  • Run 3Long easy run 50 min

Week 10 (Race Week)

  • Run 1Easy 25-30 min
  • Run 2Light tune-up: 15-20 min easy + 4 x 20 sec strides
  • Run 310K race or time trial with relaxed warm-up

When Heat or Fatigue Wins

In heat, prioritize HR over pace. Missed long run → next long at 90% duration. Fourth run only after solid weeks, short and easy.

Practical Takeaway

Arrive able to run easy for the distance, then race with patience. Recover a few easy days before a repeat 10K or half build.

FAQ

Do I need a recent 5K first?

Strongly preferred. If continuous running still feels shaky, finish a beginner 5K block before this plan.
