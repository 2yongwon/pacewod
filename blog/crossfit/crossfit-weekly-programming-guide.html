CrossFit Weekly Programming: How to Structure Strength, Metcons, and Rest

Updated August 2026 · 4 min read

Random hard WODs work briefly, then flatten you. Programming is fatigue accounting: strength, metcons, skills, and rest share one recovery budget.

Hybrid notes: Running and CrossFit Balance. Build sessions with the WOD Generator and Workout Library.

Weekly Budget and Intensity

Spend three currencies: neural/strength, metabolic, and local tissue (grip, shoulders, lumbar, Achilles). Different-looking hard days that spend the same currency still stack.

For 4–5 days/week non-competitors: ~70–80% easy/moderate · ~15–25% hard · infrequent true tests. Cap Hard days at 2–3 total (including hard runs). If every class is RPE 9, distribution is inverted.

Hard-Day Spacing

  • Max lower strength vs high-volume squat/lunge metcons: 48+ hr
  • Heavy Olympic lifting vs Fran/Isabel-style cycling: ≥1 day
  • Dense gymnastics (MU/HSPU): 2–3×/week max, 48 hr if joints sensitive
  • After a benchmark PR: 24–48 hr easy (technique, Zone 2) — not another chipper

Sample Weeks

3 days: Mon lower strength + short metcon · Wed upper/OL + skill + moderate metcon · Fri For Time/longer AMRAP. Optional Sat Zone 2.

4 days (sweet spot): Mon heavy squat/DL + ≤10 min metcon · Wed OL + skill + 12–15 min · Fri upper/light lower + harder For Time · Sat longer engine (moderate loads). Hard = Mon/Fri/Sat.

5 days: add Tue gymnastics + aerobic Zone-3 metcon (row/bike bias). Tue/Wed must stay moderate — if Wed becomes a hero WOD, drop to 4 days.

6 days: only with honest easy days + non-negotiable Sunday rest. Strength→metcon same day: heavy (≥80%, ≤6 reps) → metcon ≤10–12 min at ≤45% cycling loads. Session target 60–75 min.

Hybrid Running Notes

Long run after rest or upper-biased CF. Quality run 48 hr from heavy lower/lunging. Easy Zone 2 can replace aerobic CF slots — don’t stack “easy” run + hard metcon. Cap Hard at 2–3 across both sports. Deload every 4–6 weeks (~40–50% volume/intensity).

Practical Takeaway

Pick the lowest frequency you can finish for 8–12 weeks. Label days Easy/Moderate/Hard before the week starts, and scale so each day spends the currency you budgeted.

FAQ

Is 5–6 days too much?

Not if intensity is honest. Five days with two hard sessions can work; five RPE 8–9 metcons cannot. Cut hard days before frequency when sleep/mood/performance slide.

Strength and metcon same day?

Default skill → strength → metcon. Separate days when both need to be hard. After heavy lower, keep the metcon short and lighter.
